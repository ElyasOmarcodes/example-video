# د لعل مسجد ویډیو: په Cowork کې د متحرکو کلیپونو جوړول

## ولې Cowork؟

هیګزفیلډ نامحدود (unlimited) جوړونه یوازې په Claude Cowork، Claude chat او ChatGPT کې اجازه ورکوي. په Claude Code کې ترې کار نشي اخیستل کېدای. ځکه ټول کلیپونه په Cowork کې جوړوو، چې کریډیټ مصرف نشي.

## په زیپ کې څه دي؟

| فولډر یا فایل | څه دي |
|---|---|
| `PROMPT.md` | ټوله لارښوونه، په انګلیسي. همدا متن Cowork ته پیسټ کېږي |
| `pack/motion/` | د بلېنډر متحرک شاټونه، یعنې د کامرې حرکت. دا د ویډیو مرجع ده |
| `pack/first/` | د هر شاټ لومړی فرېم، د ترکیب لپاره |
| `pack/plates/` | ۱۴ تصویب شوي حقیقي انځورونه، د لید او رنګ لپاره |

## ګام په ګام

1. په Cowork کې ډاډ ترلاسه کړئ چې د **Higgsfield** کنکټر وصل دی.
2. زیپ په Cowork کې ورته ورکړئ (attach)، یا یې خلاص کړئ او فولډر ورته وښیئ.
3. د `PROMPT.md` ټول متن کاپي او پیسټ کړئ، بیا یې ولېږئ.
4. Cowork دا کارونه په ترتیب کوي:
   - لومړی ۸ د لید پاڼې (A1 تر A8): د مسجد خښتې او ګنبد، زغروال موټر، کمانډو، ښار، سټوډیو، نقشه، مدرسه او محکمه.
   - بیا د هر شاټ پیل انځور (Nano Banana Pro).
   - بیا متحرک کلیپ (Seedance 2.5)، چې د بلېنډر کامرې حرکت دقیق تعقیبوي.
5. په پای کې `lalmasjid-clips.zip` درکوي. هغه دلته ماته راولېږئ. زه یې ایډېټ کوم:
   - د نهضت لوګو
   - غږ
   - سبټایټل
   - موشن ګرافیک

## یادونې

- ټول ۶۱ شاټونه دي. که Cowork په یوه ناسته کې ټول جوړ نه کړي، ورته ووایاست: «له `progress.md` نه دوام ورکړه».
- که نامحدود رد شو، Cowork به ودرېږي او کریډیټ به نه لګوي.
- که یو کلیپ خراب و، ورته ووایاست: «L08_2 بیا جوړ کړه».
