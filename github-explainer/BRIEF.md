## Intent

Premium 3D / 2.5D motion-graphics explainer about GitHub, in Arabic, vertical 9:16.
Gemini / NotebookLM product-film feel: glassmorphism panels, depth, parallax, kinetic
Arabic typography, smooth camera moves. Not a slideshow; the scene evolves every 2–5 s
and every spoken concept triggers its visual at the moment it is said.

## Assets

- assets/audio/voiceover.mp3 — the user's final Arabic narration. MASTER TIMELINE. Used
  verbatim, never regenerated, never trimmed. No TTS anywhere in this project.

## Customizations

- Quiet modern tech music bed under the voice, ducked under speech.
- Subtle SFX on UI reveals, commits, branch split/merge, PR approve, Actions stages.
- Key Arabic phrases only (no full subtitles); English kept for product names
  (GitHub, Git, Repository, Pull Request, GitHub Actions, Open Source, main, README.md).

## Notes

- Arabic must be RTL with letters connected; never split Arabic words into letters.
- Fill the whole 9:16 canvas edge to edge; restrained palette (graphite, blue, cyan, violet).
- Timing is driven by word-level alignment of the voiceover (see timing/aligned.json).
