# Premiere Pro project (FCP7 XML)

Import: Premiere Pro → File → Import → `Ikhtilaf_Pashto_Premiere.xml`.

Sequence 1080×1920, 30 fps, 239.5 s:
- V1 — `renders/ikhtilaf-pashto.mp4` (the finished animation; picture only)
- A1 — `assets/audio/voiceover.mp3` (voice)
- A2 — `assets/audio/music.m4a` (news music, already very low)
- A3 — `assets/audio/sfx.m4a` (sound effects)
- One marker per scene, named with the scene heading.

If Premiere asks for missing media, keep the repo folder structure and point it to the `ikhtilaf-pashto` folder (Link Media → search).
