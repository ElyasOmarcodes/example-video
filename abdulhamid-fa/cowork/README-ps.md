# د سلطان عبدالحمید ویډیو په Claude Cowork کې — لارښود

## ۱. Cowork او عادي چټ کې څه توپیر دی؟

دواړه په هیګزفیلډ کې ستاسو نامحدود ټرایل کارولی شي. خو په دې ټکي کې توپیر لري:

| | عادي چټ (claude.ai) | Claude Cowork |
|---|---|---|
| د هیګزفیلډ نامحدود ټرایل | ✅ | ✅ |
| انځور، ویډیو کلیپ او غږ جوړول | ✅ | ✅ |
| فایلونه ښکته کول او په ffmpeg سره ایډېټ کول | محدود (کېدای شي یوازې لنډې فایلونه) | ✅ بشپړ |
| یو وروستی MP4 جوړول | ډېر ځله نه کېږي | ✅ |

**نتیجه:** **Cowork** وکاروئ، ځکه ټول کار، تر وروستي MP4 پورې، هلته کېږي. عادي چټ یوازې کلیپونه جوړولی شي؛ بیا به کلیپونه ماته راولېږئ چې ایډېټ یې کړم.

## ۲. له پیل مخکې

1. په Cowork کې ډاډ ترلاسه کړئ چې د **Higgsfield** کنکټر وصل دی: Settings → Connectors → Higgsfield.
2. ستاسو ټرایل تر **۱۸ نومبر ۲۰۲۶، ۰۲:۱۸ UTC** پورې دی. له هغه وروسته د Ultra میاشتنی فیس اخیستل کېږي. که یې نه غواړئ، auto-renewal لغو کړئ.

## ۳. ګام په ګام

1. په Cowork کې نوی کار (task) پرانیزئ.
2. د `refs` فولډر څلور انځورونه ورسره ونښلوئ (attach):
   - `01_sultan_abdulhamid.jpg`
   - `02_herzl.jpg`
   - `03_karasu.jpg`
   - `04_mahmud_shevket.jpg`
3. د `PROMPT.md` ټول متن کاپي او پیسټ کړئ، بیا یې ولېږئ.
4. Cowork لومړی د سلطان انځور (K1) او د غږ یوه ازمایښتي جمله درښیي. که ښه وي، ورته ووایاست: «ښه ده، دوام ورکړه».
5. بیا Cowork په خپله دا کارونه کوي: ۱۴ کلیپونه، ۱۷ غږیزې جملې، موسیقي او غږیز اغېز، او په پای کې ایډېټ.
6. په پای کې `abdulhamid-ep1-cinematic.mp4` او د ټولو خامو فایلونو zip درکوي.

## ۴. په پرامپټ کې څه دي (لنډیز)

- **موضوع:** «آخرین روز در یلدز» — د ۱۹۰۹ کال ۲۷ اپرېل، د عبدالحمید دوم برکناري او سالونیک ته تبعید.
- **۱۴ شاټه:** د یلدز ماڼۍ، د شپې اورګاډی، نقشه، جاسوسان، هرتزل، کړکۍ ته ولاړ سلطان، سالونیک، بغاوت، د حرکت اردو، مجلس، هیئت، روانېدل.
- **څلور کرکټرونه:** سلطان، هرتزل، اسعد پاشا او محمود شوکت پاشا، د حقیقي انځورونو په مرسته.
- **د هر شاټ لپاره:**
  - د انځور پرامپټ (GPT Image 2.6، 2K، 9:16)
  - د حرکت پرامپټ (Seedance 2.5، omni_reference)
  - دقیق مهال
  - د کامرې حرکت
- **غږ:** ۱۷ فارسي جملې، د بشپړ متن سره (Seed Audio، ژور نارینه غږ).
- **موسیقي:** سوینو، عثماني رنګ لرونکې ارکسترا. سربېره پر دې څلور غږیز اغېز.
- **ایډېټ:**
  - ترتیب او ټرانزیشنونه
  - یو شان رنګ
  - غږ برابرول (−14 LUFS)
  - فارسي سبټایټل او د پای کارت
  - په 1080×1920 کې MP4

## ۵. که ستونزه پېښه شي

- **که یو کلیپ خراب جوړ شي:** Cowork ته ووایاست: «C05 بیا جوړ کړه، مخونه دې د مرجع سره سم وي».
- **که په یوه کال کې نامحدود رد شي:** پرامپټ Cowork ته وایي چې ودرېږي او له کریډیټ نه یې ونه لګوي.
- **که Cowork د MP4 ایډېټ ونشي کړای:** ترې وغواړئ چې د خامو فایلونو zip درکړي. هغه zip دلته ماته راولېږئ، او زه وروستۍ ایډېټ جوړوم.

## ۶. Blender

Blender او د blender-skills ۲۸ سکیلونه دلته (Claude Code) نصب او ازمویل شوي دي، خو Cowork نشي کولی Blender وچلوي. ځکه مې د هر شاټ د کامرې حرکت او ترکیب په پرامپټ کې دقیق لیکلی دی. که د Blender پرېویز انځورونه (د کامرې زاویه او ترکیب) هم غواړئ، دلته یې جوړولی شم، او تاسو یې د اضافي مرجع په توګه Cowork ته ورکولی شئ.
